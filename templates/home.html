📡 REST API Demo

This project includes a REST API endpoint for placing orders. You can test it using tools like Postman or curl.

API Endpoint:
POST /orders/api/orders/place/

Headers:
Content-Type: application/json
Authorization: Token YOUR_TOKEN (requires authentication)

Body:
{
  "items": [
    {"menu_item_id": 1, "quantity": 2, "special_instructions": "Extra spicy"}
  ],
  "delivery_address": "123 Main St, City",
  "notes": "Please ring the bell"
